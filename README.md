# 📚 나의 책장 — 카카오톡 스터디를 대체하는 완전 로컬 언어학습 앱

**책 한 권 + 선생님 mp3 + 교재 사진**으로 매일 공부하고, **내 녹음·필기 사진·메모를
날짜별로 기록**하는 앱. 퀴즈(6종)와 간격 반복(SRS)은 보조 복습 기능. 와이파이 꺼도
전부 동작 (외부 요청 0회, 녹음도 서버 전송 없이 브라우저 안에만 저장).

## 실행 방법

- 매일 쓸 때: **`시작하기.command` 더블클릭** (처음 한 번은 우클릭 → 열기)
- 개발: `npm run dev` / 빌드: `npm run build`

## 화면 구성

1. **책장(홈)** — 언어 탭(🇨🇳🇬🇧🇯🇵), 책 표지 카드, 진행도, 복습 배지, 오늘 목표
2. **책 페이지** — 챕터 목록(자유 선택, 잠금 없음) + 전체 내용 훑어보기 탭
3. **챕터(학습) 화면** — 이 앱의 중심 화면:
   - 📂 소카테고리별 📖 본문(+선생님 녹음) · 🖼 첨부 이미지(교재 스캔) · 🔤 새단어 · 📐 문법
   - **📝 내 학습 기록**: 날짜별 타임라인 — 🎙 앱에서 바로 녹음 (또는 파일 업로드) + 🖼 필기 사진 첨부 + 메모
   - 🎯 퀴즈로 복습 (선택), 📌 완료 표시 (진도 체크, 퀴즈 없이도 가능)
4. **퀴즈** — 🎯 버튼을 누르면 **범위를 고르는 창**이 뜹니다
   - 범위: 소단원 / 이 챕터 / 교재 전체 / 오늘 복습할 것 / 최근 일주일 틀린 것
   - 문항 수와 문제 유형(뜻 고르기 · 짝 맞추기 · 문장 조립 · 빈칸 · 타이핑 · 듣기)을 켜고 끌 수 있고,
     **범위마다 몇 문제 낼 수 있는지 미리 보여줍니다** (mp3가 없으면 듣기는 아예 비활성)
5. **프로필** — 스트릭 달력, XP, 학습 단어 수, 설정(일일 목표·하트·효과음·저장 용량)

## 📐 콘텐츠 구조

```
책 (Unit)
└─ 챕터 (Lesson, 교재의 '과')
   └─ 소카테고리 (Section — 예: 회화1, 본문, 독해)
      ├─ 📖 본문 전체 (passageText 통 붙여넣기 + passageTranslation 전체번역 + passageAudio 통 녹음)
      ├─ 🔎 문장별 세부 (passages — 선택, 퀴즈·문장단위 듣기용. passageText에서 자동 분리 가능)
      ├─ 🔤 새단어 (words)
      ├─ 📐 문법 (grammar — 제목·설명·예문)
      └─ 🖼 첨부 이미지 (images — 교재 페이지 스캔 등 여러 장)
```

**본문은 긴 지문을 한 덩어리로 붙여넣는 게 기본**입니다 (문장 하나하나 입력칸에 칠 필요 없음).
편집 화면에서 원문 전체 + 번역 전체를 큰 텍스트박스에 붙여넣고, 필요하면 "✂️ 문장으로 자동 분리"
버튼으로 퀴즈용 문장 목록을 만들 수 있어요 (선택 사항). 퀴즈는 이 문장별 세부(뜻이 채워진 것만)와
문법 예문 = 문장 풀, 새단어 = 단어 풀로 자동 출제됩니다.

**언어**: 책마다 자기 언어를 갖습니다. 새 책을 만들 때 편집 화면 상단에서 고르세요.
언어를 늘리고 싶으면 `src/data/index.ts` 의 `LANGUAGES` 에 한 줄만 추가하면 됩니다.

**책 종류(track)**: 🌱 기초 / 📚 교재·미디어 / 📇 단어장 — 편집 화면 상단에서 선택.
단어책(예: HSK6급단어)은 Day를 챕터로, 새단어 위주 소카테고리로 만들면 됩니다.
단어책의 단어도 SRS 복습 풀에 자동으로 섞입니다.

## ✏️ 책 추가·편집 (앱 안에서, 재빌드 불필요)

- 책장의 **➕ NEW_BOOK.EXE** 또는 책 창의 주소창 **✏️ 편집**
- 챕터 → 소카테고리 → 본문/새단어/문법을 직접 입력 → 💾 저장 (localStorage)
- 언제든 단어·본문·챕터·소카테고리를 **추가로 더 넣을 수 있음**
- 내장 책을 편집하면 사본이 우선 적용, 언제든 "원본으로 되돌리기" 가능

### 🤖 AI로 만들어 넣기 (추천 워크플로)

1. 클로드에게 요청:
   > 아래 JSON 형식으로 『맛있는 중국어 L2』 1과 본문(passageText 통 지문 + passageTranslation 전체번역)과
   > 새단어·문법을 만들어줘. 뜻은 한국어, reading에 병음.
   ```json
   {
     "title": "맛있는 중국어 L2",
     "emoji": "🥟",
     "sourceType": "textbook",
     "sourceTitle": "맛있는 중국어 Level 2",
     "lessons": [
       {
         "title": "1과 — 제목",
         "context": "한 줄 설명",
         "sections": [
           {
             "title": "회화",
             "passageText": "你去哪儿？我去学校。你现在去商店吗？",
             "passageTranslation": "어디 가요? 나는 학교에 가요. 지금 가게에 가요?",
             "words": [
               { "text": "去", "reading": "qù", "meaning": "가다" }
             ],
             "grammar": [
               { "point": "동사 + 吗 의문문", "explanation": "문장 끝 吗로 의문문", "examples": [ { "text": "你忙吗？", "meaning": "바빠요?" } ] }
             ]
           }
         ]
       }
     ]
   }
   ```
   - `passages`(문장별 세부, 퀴즈용)는 생략해도 되고, 넣고 싶으면 `{ "text", "meaning", "tokens" }` 배열로 추가
2. 앱에서 새 책(또는 편집) → **🤖 JSON 붙여넣기** → 불러오기 → 저장

- 예전 평면 형식(`"words"`/`"sentences"`)도 그대로 읽힙니다 (자동으로 '본문' 섹션 하나로 취급)
- 영어는 reading/tokens 생략 가능 (공백 자동 분절)
- **`"id"`와 `"lang"`은 쓰지 않아도 됩니다** — 불러올 때 자동으로 붙습니다
- 이미 있는 과를 AI로 **다시 만들어 붙여넣어도**, 단어·문장 텍스트가 같으면
  그동안 쌓인 복습 숙련도가 그대로 이어집니다
- 문장·대사는 **의역·축약**으로 (원문 그대로 복사 금지 — 저작권)

## 🔊 mp3 넣는 방법 (두 가지 다 지원)

**A) 앱에서 직접 업로드 (폴더 안 건드림)**
- 편집 화면의 각 항목 mp3 칸 옆 **⬆ 버튼** → 파일 선택 → 브라우저 DB(IndexedDB)에 저장
- ✓ 표시가 뜨면 업로드 완료. 바로 🔊로 미리듣기 가능
- ⚠️ 브라우저 데이터를 지우면 사라짐 (프로필에서 사용 용량 확인 가능)

**B) 폴더에 넣기 (파일 영구 보존)**
- mp3 칸(또는 JSON `"audio"`)에 파일명 입력 — 예: `mccs/l1-ch01.mp3`
- 파일을 `public/audio/<언어>/` 에 넣고 다시 빌드 (또는 `dist/audio/<언어>/`에 바로)

**파일이 실제로 있는(업로드됐거나 폴더에 있는) 항목만** 🔊가 뜨고 듣기 문제가 출제됩니다.

교재 페이지 사진 등 **이미지도 같은 방식**(편집 화면 소카테고리 안 "🖼 첨부 이미지" → ＋ 이미지 추가)으로
브라우저 안(IndexedDB)에 저장됩니다.

## 📝 내 학습 기록 (카카오톡 스터디 대체)

각 챕터 화면 하단에 날짜별 타임라인이 있습니다.
- **✍️ 쓰기 연습**: 오늘 직접 써 본 문장을 여러 줄로. 카드에 강조돼 보입니다
- **🎙 말하기 녹음**: 마이크로 바로 녹음 (완전 로컬, 어디로도 전송 안 됨) — 또는 📁 오디오 파일 업로드.
  **하루에 여러 개** 남길 수 있어요 (문장별로 따로 읽는 경우)
- **🖼 필기 사진**: 내 필기·연습장 사진 **여러 장** (모바일은 카메라로 바로 촬영 가능)
- 한 줄 메모도 같이 남길 수 있음
- 기록은 날짜 역순으로 쌓이고, 🗑로 개별 삭제 (딸린 녹음·사진도 함께 지워집니다)
- 책 페이지에도 "📝 N일 기록" 배지로 표시됨

## 학습 시스템

- **SRS**: 항목별 숙련도 0~5, 복습 간격 1·3·7·14·30일, 책장 상단에 복습 배지.
  **단어와 문장 모두** 각자 카드를 갖고, 자주 틀린 것·복습일이 지난 것이 더 자주 나옵니다
- **문제 자동 생성**: 숙련도가 오르면 어려운 유형으로 (고르기 → 조립·빈칸 → 타이핑).
  오답 보기는 같은 소단원·같은 품사·비슷한 길이에서 골라 그럴듯하게 만듭니다.
  중국어·일본어 문장은 **교재에 등록된 새단어로 분절**해서 타일을 만들어요
  (교재를 채울수록 분절이 좋아집니다)
- **스트릭·XP·일일 목표·하트** (하트는 복습으로 회복, 설정에서 끄기 가능)
- **진도는 세 가지를 따로 보여줍니다** — 셋을 하나로 합치지 않아요
  - 📌 **완료 표시**: 손으로 켜는 체크. 퀴즈 없이도 진도를 남길 수 있고, 챕터마다 따로 켜고 끌 수 있어요
    (7과만 완료해도 1~6과가 딸려오지 않습니다)
  - 💮 **숙달도**: 퀴즈로 실제로 익힌 비율 (복습 숙련도 3 이상). 책·챕터·소단원 단위로 표시
  - ✏️ **채운 정도**: 교재를 얼마나 채워 넣었는지. 빈 소단원은 점선 카드로 보여서
    "여기 아직 안 채웠다"가 눈에 들어옵니다
- 단어·문장을 고치거나 챕터를 중간에 끼워 넣어도 **복습 기록과 학습 기록이 따라옵니다**
  (모든 항목이 고유 id를 갖기 때문)
- 모든 기록은 localStorage/IndexedDB — 브라우저 데이터를 지우면 사라지니
  **프로필 · 통계 → 백업 · 복원**에서 zip으로 내보내 두세요

## 🛠 개발

```bash
npm install
npm run dev          # 개발 서버
npm test             # 테스트 (정규화 · 마이그레이션 · 퀴즈 엔진)
npm run build        # 빌드
npm run data:migrate # 내장 교재 JSON을 최신 스키마로 변환 (보통 쓸 일 없음)
```

설계 문서는 `docs/PRD.md`(목표 스키마·퀴즈 엔진 명세)와
`docs/RESTRUCTURE.md`(현행 코드 갭 분석·작업 순서)에 있습니다.
